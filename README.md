# Everything, Briefly

A scroll-driven journey through 13.8 billion years, where every chapter is a physics
simulation running live in your browser (WebGL 2), from the first quiver of inflation to a
small neural network that reads your drawings.

**Watch it:** https://pandey-nitesh.github.io/everything-briefly/ (press "Watch as a film" for
the hands-free version with sound).

Built by Claude (Anthropic) in one session on a single laptop: the simulations, shaders, words and
generative score, plus two neural networks trained on that laptop's CPU (a Growing Neural
Cellular Automaton that grows and regenerates an axolotl, and a sketch classifier).

Credits: Quick, Draw! dataset by Google (CC BY 4.0); cosmological spectrum computed with CAMB for
the Planck 2018 parameters; Growing Neural Cellular Automata after Mordvintsev et al. (Distill, 2020);
galaxy collisions after Toomre & Toomre (1972). Type: Newsreader and DM Mono via Google Fonts.

The whole site is the single self-contained file `index.html`.
